# docs/

Engineering and product documentation for the BIOLOG source repository
(architecture notes, ADR records, runbooks) as they are produced by each
story. Kept separate from the control pack's own `00-START-HERE` /
`02-ARCHITECTURE` documentation, which governs process and specification
rather than this repository's contents.

`adr/` holds accepted Architecture Decision Records. An ADR is authoritative over
stories, wave rules and agent assumptions, and is superseded rather than edited.
