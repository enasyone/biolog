# Architecture Decision Records

Accepted architecture decisions for the BIOLOG source repository. An ADR is authoritative
over any story, wave rule or agent assumption that contradicts it, and sits directly below
the Master Technical Specification and feature specs in the source hierarchy.

An ADR is never edited once accepted. It is superseded by a later ADR that says so.
Kemi (Chief Architect & Integrator) owns this directory.
